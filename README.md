# TikOps Stream Deck Plugin Releases

This repository contains binary releases for the TikOps Stream Deck plugin.

## Download

[Download the latest release](https://github.com/TikOpsIO/streamdeck-plugin-releases/releases/latest)

Direct asset: [com.tikops.streamdeck.streamDeckPlugin](https://github.com/TikOpsIO/streamdeck-plugin-releases/releases/latest/download/com.tikops.streamdeck.streamDeckPlugin)

## Installation

1. Download `com.tikops.streamdeck.streamDeckPlugin`
2. Double-click the file to install into the Elgato Stream Deck app
3. Open the Stream Deck software and look for TikOps actions in the catalog
